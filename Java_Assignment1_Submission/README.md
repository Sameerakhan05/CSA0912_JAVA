## Folder structure
Each Task01–Task12 folder contains a separate Java program. Task03 and Task08 are the two
"Complete the Code" programs from the assignment. Task11 is an integrated implementation
and Task12 implements the changed requirements.

## Compile and run
Open a terminal in the required task folder and run:
    javac Main.java
    java Main

Use the matching filename/class for files named ParkingFacility.java, FeeDemo.java,
SmartParkingSystem.java and AdaptedParkingSystem.java.

## Task results
- Task01: Models a vehicle and parking slot.
- Task02: Demonstrates jagged arrays, input validation and safe decimal billing.
- Task03: Allocates and releases slots; matches the expected output in the assignment.
- Task04: Demonstrates overloaded constructors and constructor chaining.
- Task05: Demonstrates a static ticket counter.
- Task06: Demonstrates hierarchical/multilevel inheritance and constructor order.
- Task07: Demonstrates overriding and Object methods.
- Task08: Completes FeeDemo using abstraction, inheritance, interface and polymorphism.
- Task09: Demonstrates abstract class and interface default/static methods.
- Task10: Demonstrates private fields, validated setters and autoboxing.
- Task11: Demonstrates integrated entry/exit, tickets, fees, duplicate checking and tests.
- Task12: Adds e-bikes, delivery vans, visitor pass representation and five unequal floors.
